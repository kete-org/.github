## 👋 Welcome

Kete builds AI-powered products that help businesses run smarter and help developers ship faster. Our work centres on two products:

### 🧺 KeteOS: The AI Operating System for Business
*Connect your business. Deploy your AI workforce. Run smarter.*

KeteOS gives SMEs and growing businesses one platform to run the whole organisation:

- **Business apps and data** in one place
- **AI employees** that understand your business, recommend actions and carry out tasks within the permissions you set
- **Automation and intelligence** across everyday workflows
- **Integrations** with the tools you already use: CRM, accounting, spreadsheets, email, WhatsApp, project tools, documents and dashboards

### 💻 Kete Code: AI coding workbench
A developer environment with a built-in coding agent that works alongside engineers to write, understand and change code.
